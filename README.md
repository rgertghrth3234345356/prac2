# Dependency Visualizer

CLI-приложение на Python для построения и визуализации графа зависимостей
Java-пакетов из Maven-репозитория. POM-файлы загружаются напрямую по HTTP(S),
а XML разбирается стандартными средствами Python. Maven и сторонние библиотеки
для получения зависимостей внутри приложения не используются.

Проект реализует требования практической работы, вариант №5.

## Возможности

- Параметры запуска задаются аргументами командной строки.
- Чтение прямых зависимостей из Maven POM.
- Отдельный режим вывода только прямых зависимостей (`--direct`).
- Тестовый режим на JSON-файле с вершинами, названными большими латинскими
  буквами.
- Построение транзитивного графа итеративным DFS без рекурсии.
- Исключение пакетов, имя которых содержит указанную подстроку (`--filter`).
- Сохранение циклических рёбер и их обозначение при визуализации.
- Вычисление порядка загрузки зависимостей (`--order`) для ациклического графа.
- Генерация Mermaid и, по запросу, ASCII-дерева (`--ascii`).
- Вывод параметров CLI в формате `ключ=значение` (`--show-config`).

## Требования и запуск

- Python 3.10 или новее.
- Для тестирования: `pytest`.
- Для работы приложения внешние Python-пакеты не требуются.

Запуск из корневого каталога проекта:

```bash
py -m src.main --package A --repository test-repository.json --test-mode
```

На Windows можно использовать `run.bat`. При запуске без аргументов он
выполняет демонстрационный пример. Если аргументы указаны, они передаются
приложению без изменений:

```bat
run.bat --package A --repository test-repository.json --test-mode --ascii
```

## Параметры командной строки

| Параметр | Обязательный | Описание |
|---|---:|---|
| `--package` | да | Maven-координаты `groupId:artifactId:version` (допускается `:classifier`); в тестовом режиме — имя вершины, например `A` |
| `--repository` | да | URL Maven-репозитория или путь к JSON-файлу |
| `--test-mode` | нет | Использовать локальный JSON вместо Maven-репозитория |
| `--ascii` | нет | Дополнительно вывести ASCII-дерево |
| `--direct` | нет | Вывести только прямые зависимости корневого пакета |
| `--filter TEXT` | нет | Не включать пакеты, имя которых содержит `TEXT` |
| `--order` | нет | Вывести порядок загрузки: сначала зависимости, затем зависящие от них пакеты |
| `--show-config` | нет | Напечатать все параметры в формате ключ-значение |

Для реального режима указывается базовый URL Maven-репозитория, например:

```text
https://repo.maven.apache.org/maven2
```

Координаты Maven имеют вид `groupId:artifactId:version`. Дополнительно
принимается форма с classifier: `groupId:artifactId:version:classifier`.
Для загрузки POM classifier не используется: Maven POM публикуется по
координатам groupId, artifactId и version.

## Примеры

### Этап 1. Проверка параметров CLI

```bash
py -m src.main --package A --repository test-repository.json --test-mode --ascii --filter TEST --show-config
```

### Этап 2. Прямые зависимости

Тестовый режим:

```bash
python -m src.main --package A --repository test-repository.json --test-mode --direct
```

Реальный Maven-пакет:

```bash
py -m src.main --package org.slf4j:slf4j-simple:2.0.13 --repository https://repo.maven.apache.org/maven2 --direct
```

### Этап 3. Транзитивный граф, фильтр и циклы

```bash
py -m src.main --package A --repository test-repository.json --test-mode
py -m src.main --package A --repository test-repository.json --test-mode --filter E
```

В тестовом файле можно создать цикл, например `A -> B -> C -> A`.
DFS завершится, а циклическое ребро останется в графе и будет отмечено
в ASCII-дереве как `(цикл)`.

### Этап 4. Порядок загрузки

```bash
py -m src.main --package A --repository test-repository.json --test-mode --order
```

Алгоритм выводит зависимости раньше пакетов, которые от них зависят. Для
графа с циклом линейный порядок загрузки не существует; программа сообщает
об этом вместо вывода некорректной последовательности.

### Этап 5. Визуализация

```bash
py -m src.main --package A --repository test-repository.json --test-mode --ascii
```

Mermaid-описание выводится всегда. ASCII-дерево добавляется только при
наличии `--ascii`.

## Тестовый репозиторий

Файл `test-repository.json` описывает ориентированный граф. Ключ — пакет,
значение — список его непосредственных зависимостей. Ребро `A -> B` означает,
что пакет A зависит от B.

```json
{
  "A": ["B", "C"],
  "B": ["D"],
  "C": ["D", "E"],
  "D": ["F"],
  "E": [],
  "F": [],
  "G": ["A"]
}
```

В тестовом режиме все имена должны состоять только из больших латинских букв.
Каждый пакет, указанный в списке зависимостей, должен присутствовать в JSON
как отдельный ключ. Для листовой вершины используется пустой список.
Некорректные ссылки на неописанные вершины отклоняются с сообщением об ошибке.

## Примеры для трёх пакетов

В каталоге `docs/examples/` находятся Mermaid-описания для корневых пакетов
`A`, `B` и `G`. Они создаются следующими командами:

```bash
py -m src.main --package A --repository test-repository.json --test-mode
py -m src.main --package B --repository test-repository.json --test-mode
py -m src.main --package G --repository test-repository.json --test-mode
```

## Сравнение со штатным Maven

В `docs/MAVEN_COMPARISON.md` приведены проект-потребитель Maven, команды
`mvn dependency:tree` и запуска приложения, ожидаемая структура дерева и
объяснение ограничений учебного парсера. Сравнивается поддерево выбранного
артефакта: Maven показывает также корневой проект-потребитель, а приложение
строит граф от самого анализируемого артефакта. Сравнение выполняется внешней
командой Maven; приложение само Maven не запускает.

## Структура проекта

- `src/argument_parser.py` — CLI и проверка аргументов.
- `src/config.py` — неизменяемая конфигурация приложения.
- `src/package_info.py` — модели Maven-пакета и POM.
- `src/repository_reader.py` — HTTP-загрузка и разбор POM XML.
- `src/dependency_graph.py` — ориентированный граф (список смежности).
- `src/graph_builder.py` — тестовый режим, итеративный DFS, фильтр и порядок загрузки.
- `src/graph_visualizer.py` — Mermaid и ASCII.
- `src/main.py` — точка входа и вывод результатов.
- `tests/` — автоматические тесты.
- `docs/` — демонстрационные Mermaid-графы и сравнение с Maven.

## Алгоритмы и ограничения

DFS реализован без рекурсии: стек хранит текущие вершины и итераторы их
смежных вершин. Уже обнаруженные вершины повторно не раскрываются, поэтому
циклы не приводят к бесконечному обходу. Рёбра цикла сохраняются.

Порядок загрузки строится DFS postorder: зависимость добавляется в результат
после обхода её зависимостей. При цикле операция завершается понятной ошибкой.

Парсер POM поддерживает обычные зависимости, свойства текущего POM,
локальный `dependencyManagement`, scopes `compile` и `runtime`, а также
classifier. Прямые `optional`-зависимости включаются в граф корневого пакета,
но не распространяются транзитивно. Не реализован полный Maven Model Builder: в частности, полное
наследование parent POM, импорт BOM, профили, все правила exclusions,
version mediation и разрешение конфликтующих версий. Поэтому для сложных
проектов результат может отличаться от `mvn dependency:tree`. Подробности и
пример сравнения описаны в `docs/MAVEN_COMPARISON.md`.

## Тестирование

Установить pytest (только для запуска тестов):

```bash
py -m pip install pytest
py -m pytest -q
```

Дополнительные тесты на стандартном `unittest`:

```bash
py -m unittest discover -v
```git log --oneline

Приложение не импортирует pytest и не зависит от сторонних библиотек.
